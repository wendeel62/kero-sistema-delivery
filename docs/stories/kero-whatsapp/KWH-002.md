# KWH-002: Row Level Security — Isolamento Multi-Tenant
## Definição
Configurar RLS (Row Level Security) no PostgreSQL para garantir que cada usuário veja apenas seus próprios dados no sistema WhatsApp. Sem isso, qualquer SQL bug ou query maliciosa poderia expor dados de outros tenants.
## SQL — RLS
```sql
-- Habilitar RLS em todas as tabelas
ALTER TABLE devices ENABLE ROW LEVEL SECURITY;
ALTER TABLE conversations ENABLE ROW LEVEL SECURITY;
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
ALTER TABLE contacts ENABLE ROW LEVEL SECURITY;

-- Políticas: cada tabela filtra por user_id via FK em devices
-- devices: usuário só vê seus próprios devices
CREATE POLICY devices_tenant ON devices FOR ALL
  USING (user_id = current_setting('app.current_user_id')::uuid)
  WITH CHECK (user_id = current_setting('app.current_user_id')::uuid);

-- conversations: via FK devices → user_id
CREATE POLICY conversations_tenant ON conversations FOR ALL
  USING (
    EXISTS (SELECT 1 FROM devices WHERE devices.id = conversations.device_id AND devices.user_id = current_setting('app.current_user_id')::uuid)
  );

-- messages: via FK conversations → device → user_id
CREATE POLICY messages_tenant ON messages FOR ALL
  USING (
    EXISTS (
      SELECT 1 FROM conversations c
      JOIN devices d ON d.id = c.device_id
      WHERE c.id = messages.conversation_id AND d.user_id = current_setting('app.current_user_id')::uuid
    )
  );

-- contacts: via FK device
CREATE POLICY contacts_tenant ON contacts FOR ALL
  USING (
    EXISTS (SELECT 1 FROM devices WHERE devices.id = contacts.device_id AND devices.user_id = current_setting('app.current_user_id')::uuid)
  );

-- Função helper para setar contexto por request
CREATE OR REPLACE FUNCTION set_session_user(user_uuid UUID) RETURNS VOID LANGUAGE plpgsql AS $$
BEGIN
  PERFORM set_config('app.current_user_id', user_uuid::text, FALSE);
END; $$;

-- Exemplo: SET LOCAL app.current_user_id = 'uuid-do-usuario'; SELECT * FROM messages;
```
