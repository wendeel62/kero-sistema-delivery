## SUMÁRIO EXECUTIVO

O projeto KERO é um sistema de gestão para lanchonetes/restaurantes com stack moderna (React 19, TypeScript, Supabase, Edge Functions). O codebase apresenta **problemas críticos que impedem o build de produção** e múltiplas vulnerabilidades de segurança. A cobertura de testes é insuficiente e há falta de automação de CI/CD.

**Métricas Gerais:**
- **47 arquivos TSX/TS** no frontend
- **18 páginas** em src/pages
- **4 arquivos de teste** (cobertura ~5%)
- **35 vulnerabilidades npm** (19 high, 15 moderate)
- **Build: FALHANDO** (35+ erros TypeScript)

**Principais erros:**
